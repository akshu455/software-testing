# 🩺 Diabetes Prediction System

A desktop-based application that predicts whether a person is diabetic or not using input medical parameters. The system is built using a **Support Vector Machine (SVM)** classifier and a user-friendly interface using **PyQt5**.

---

## 💡 Features

- User-friendly GUI using PyQt5
- Predicts diabetes based on 5 medical features:
  - Pregnancies
  - Glucose
  - Blood Pressure
  - Skin Thickness
  - Insulin
- Trained using the **PIMA Indians Diabetes Dataset**
- Model accuracy: **80%**
- Detailed report generation with model summary and prediction result

---

## 🛠 Tech Stack

- **Frontend**: PyQt5
- **Backend**: Python (with Scikit-learn, Pandas)
- **Model**: SVM (Support Vector Machine)
- **Dataset**: PIMA Indians Diabetes Dataset from UCI
